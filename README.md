# SWATVA (स्वत्व) 🇮🇳
### *Empowering Citizens with Autonomous Welfare Scheme Discovery & Guided Application Assistance*

> **Swatva** (*स्वत्व*) translates to *Entitlement & Inherent Right*. SWATVA bridges the civic-information gap by pairing conversational AI with localized voice assistance to help citizens effortlessly discover, verify eligibility for, and apply to government welfare programs.
